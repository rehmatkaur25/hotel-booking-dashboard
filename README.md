# Hotel Booking Cancellation Dashboard

An Excel-based analytics project on hotel booking data, including pivot tables and a dashboard for tracking cancellation patterns and key booking metrics.

## Contents

- `Hotel_Booking_excel_dashboard.xlsx` — raw data, pivot tables, and dashboard visuals
- `docs/BRD_Hotel_Booking_Cancellation_Dashboard.pdf` — Business Requirements Document defining project scope, stakeholders, and functional requirements
- `docs/jira-board.jpeg` — Jira backlog (epics, user stories, acceptance criteria) tracking project delivery

## Highlights

- Pivot tables summarizing booking and cancellation trends
- Interactive dashboard for quick insights into occupancy, revenue, and booking patterns
- Requirements documented via a formal BRD with functional requirements and acceptance criteria
- Delivery tracked through a Jira backlog with epics, user stories, and acceptance criteria

## Process

Requirements were gathered and documented in a BRD before building the dashboard, and work was tracked using a Jira Kanban board — see the `docs/` folder for both artifacts.
